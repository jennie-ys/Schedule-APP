# CampusFlow 웹앱 베타 v0.2

모바일 Safari와 데스크톱 브라우저에 대응하는 반응형 PWA 프로토타입입니다. 별도의 패키지 설치가 필요 없는 HTML/CSS/JavaScript 정적 웹앱입니다.

## 로컬 실행

프로젝트 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속. 로컬 파일을 Safari에서 직접 여는 방식은 권장하지 않습니다.

## 아이폰에서 실행

이 폴더의 파일 전체를 정적 호스팅 서비스(Netlify, Cloudflare Pages, GitHub Pages 등)에 업로드하여 HTTPS 주소를 만듭니다. 아이폰 Safari에서 해당 주소를 열고 공유 메뉴 → 홈 화면에 추가를 선택합니다. 이 압축파일 자체는 아이폰 설치 파일이 아니며 공개 URL도 포함하지 않습니다.

## 기능

- 홈: 일정, 공지, 할 일 요약
- 그룹: 그룹 추가, 공지 작성, 광고성 공지 구분, 날짜 추출 데모
- 캘린더: 월 이동, 그룹별 필터, 개인 일정 추가
- 시간표: 중복 후보 과목 허용, 비충돌 조합 생성, 학점 합산
- MY: 할 일 추가/삭제/완료, 완료율
- 탐색: 가상 공고를 일정/할 일에 저장
- 로컬 저장: 브라우저 localStorage 이용

## 한계

- 서버/회원가입/그룹 구성원 간 실시간 공유 기능은 아직 없습니다.
- 공지 날짜 추출은 실제 AI가 아닌 정규식 기반 시뮬레이션입니다. 연도 생략 시 기기의 현재 연도를 사용하며, 여러 날짜의 의미를 구분하지 못합니다.
- 데이터는 사용한 브라우저/기기에만 저장됩니다. 브라우저 데이터를 삭제하면 사라집니다.
- 시간표는 시간 단위 과목만 지원하고, 조합 결과는 상위 12개까지만 보여줍니다.
- 탐색의 모집 공고는 가상 예시입니다.
- 서비스 워커/PWA는 HTTPS 또는 localhost 환경에서 동작합니다. iOS 홈 화면 아이콘 표시에는 PNG 아이콘을 추가하는 것이 좋습니다.
