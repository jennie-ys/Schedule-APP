# CampusFlow Web Beta v0.3

모바일 Safari와 데스크톱 브라우저용 정적 PWA 데모입니다.

## 실행

`python3 -m http.server 8000` 실행 후 `http://localhost:8000` 접속. GitHub Pages에서는 저장소 최상위에 `index.html`, `app.js`, `extension.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`를 각각 업로드하세요. ZIP 파일 자체 또는 상위 폴더만 업로드하면 안 됩니다.

## 기능

- 기존: 그룹·공지, 날짜 추출, 개인/그룹 캘린더, 투두, 시간표 조합, 기회 탐색
- v0.3 추가: 그룹 메시지 작성, 자유/양식 기반 공지문 템플릿 생성과 검토 후 게시, 광고 분류, 날짜/요일시간 투표, 소그룹, 담당자 있는 공유 일정, 파일 메타데이터 분류, 습관 기록, 로컬 챌린지, 생산성 현황

## 중요한 한계

- 서버/로그인/실시간 동기화 없음. 다른 사람이 동일한 그룹이나 채팅을 볼 수 없습니다.
- AI API 미연결. 공지 생성과 분류는 규칙/템플릿 기반이고 파일 본문 요약은 지원하지 않습니다.
- 파일은 이름·유형·크기만 저장하고 파일 자체는 업로드하거나 저장하지 않습니다.
- 생산성 현황은 누적 통계이며 주간 지연시간 측정이 아닙니다.
- 브라우저 로컬 저장소를 지우면 데이터가 사라집니다. 중요한 데이터를 저장하지 마세요.
- 테스트용으로 만든 서비스이며 개인정보/민감정보 업로드를 권장하지 않습니다.

## 이후 실서비스 개발

Supabase Auth, PostgreSQL/RLS, Storage, Realtime, 서버 측 AI API, 파일 본문 추출/요약, 알림, 접근권한, 개인정보처리방침 및 실제 사용자 테스트가 필요합니다.
